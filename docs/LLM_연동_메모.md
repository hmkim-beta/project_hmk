# LLM 연동 메모 (종합 평가 · AI 총평 초안)

| 구분 | 상태 |
|---|---|
| **지금 버전** | **Google Gemini API** (무료 키 사용 가능) — 동작함 |
| 폐쇄망 LLM | 연결 코드 준비됨, **주석 처리** — 서버가 마련되면 전환 |

## 1. 지금 버전: Google Gemini

### 사용 방법
1. https://aistudio.google.com/apikey 에서 **Get API key**로 무료 키를 받습니다.
2. 작성자 도구 › [종합 평가] › 작성자 총평 › **[AI 설정]** → 키 입력 → **[키 확인]** → **[저장]**.
3. **[AI 총평 초안 생성]** → 보낼 내용 확인 → 초안이 총평 칸 아래에 `[AI 초안 · Google Gemini <모델> · 검토 필요]`로 덧붙습니다.

### 키를 다루는 방식
- 키는 **작성자의 브라우저에만** 저장됩니다(기억 켜면 localStorage, 끄면 탭을 닫을 때 삭제). 작업 파일·GitHub·Vercel·Supabase에는 들어가지 않습니다.
- 키를 코드나 Vercel 환경 변수에 넣지 않은 이유: 배포 사이트를 연 누구나 그 키로 호출할 수 있게 되기 때문입니다.
- 브라우저가 `https://generativelanguage.googleapis.com/v1beta/models/<모델>:generateContent`를 직접 부릅니다(`x-goog-api-key` 헤더). 서버를 거치지 않습니다.

### 보내는 데이터
- 변경 통계, 장별 건수, 조항 번호, **바뀐 문구 일부(조항당 약 120자)**, 신설·삭제 조항 이름, 표·그림 변경, 제안 반영 통계, 작성자가 적은 변경 사유. 교범 파일 전체는 보내지 않습니다.
- 보내기 전에 탭마다 한 번 확인 창이 뜨고 **보낼 내용을 그대로 보여 줍니다**.
- ⚠ **무료 키는 보낸 내용이 Google 서비스 개선에 쓰일 수 있습니다.** 비공개 교범에는 쓰지 말고, 필요하면 유료(결제 연결) 키나 폐쇄망 LLM을 쓰세요.
- 내부망(인터넷 없음)에서는 Gemini를 쓸 수 없습니다. 그때는 [LLM 요청문 복사]로 내부 LLM 화면에 붙여넣거나 폐쇄망 LLM을 연결합니다.

### 모델
기본 `gemini-2.5-flash`. 무료 사용량을 넘거나 모델 이름이 바뀌면 [AI 설정]에서 다른 모델(`gemini-2.5-flash-lite` 등)을 고르거나 직접 입력합니다. [키 확인]을 누르면 그 키로 쓸 수 있는 모델 목록과 비교해 줍니다.

### 오류 안내
| 상황 | 화면 안내 |
|---|---|
| 키가 틀림 | "Gemini API 키가 올바르지 않습니다" |
| 무료 사용량 초과(429) | "무료 사용량을 초과했습니다 … 다른 모델을 골라 주세요" |
| 모델 이름 없음(404) | "모델을 찾을 수 없습니다" |
| 인터넷 없음 | "Gemini 서버에 연결할 수 없습니다 (내부망에서는 쓸 수 없습니다)" |

## 2. 폐쇄망 LLM으로 바꾸기 (나중에)

`src/author/js/llm.js`에서:

1. `[폐쇄망] LLM 서버 설정` 블록의 `CLOSED_CONFIG` 주석을 풀고 `endpoint`·`model`을 채웁니다. (OpenAI 호환 `POST /v1/chat/completions` — vLLM, Ollama `/v1`, TGI 등 대부분 지원)
2. `draftSummary()` 안의 **Gemini 호출 부분을 지우거나 주석 처리**하고, 그 아래 `[폐쇄망] LLM 호출` 블록의 주석을 풉니다.
3. `PROVIDER` 이름을 바꾸고, 키 입력이 필요 없으면 `ready()`가 `true`를 돌려주게 합니다.
4. `python src/build.py`로 다시 묶습니다.

### 확인할 점
- **CORS**: `file://`로 열면 출처가 `null`이라 LLM 서버가 막을 수 있습니다. 내부망 웹서버(nginx 등)에 HTML을 올리고 같은 주소의 `/llm/` 경로로 LLM을 중계하는 방식을 권장합니다.
- **인증 토큰**은 HTML에 넣지 말고 중계 서버에서 붙입니다.
- **보내는 데이터**와 요청문 길이(약 6,000자, `buildPrompt`)는 Gemini와 같습니다. 교범 등급에 따라 보안 담당과 먼저 확인합니다.

## 3. 바꿀 만한 곳

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 총평 구성·문체 | `llm.js`의 `SYSTEM` |
| 요청문에 넣는 자료 | `llm.js`의 `buildPrompt()`, `app.js`의 `llmPrompt()` |
| 기본 모델·목록 | `llm.js`의 `GEMINI_MODELS` |
| 응답 길이·온도 | `draftSummary()`의 `generationConfig` |

## 4. 향후 확장 후보

- 수정 제안 **자동 분류·중복 묶기**
- 제안 ↔ 변경 조항 **자동 연결**
