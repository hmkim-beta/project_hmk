# 종합 평가 총평과 LLM 연동 메모

| 구분 | 상태 |
|---|---|
| **총평 초안** | **통계 기반 자동 작성** (LLM 없음, 폐쇄망에서 동작) |
| **LLM 활용** | 요청문을 **TXT·PDF로 내려받아 수동 처리** |
| 폐쇄망 LLM 직접 연결 | 코드 준비됨, **주석 처리** |
| Google Gemini 연결 | 이전 버전 코드 **주석으로 보관** (지금은 사용 안 함) |

## 1. 통계 기반 총평 초안

[종합 평가] › 작성자 총평 › **[통계 기반 초안 작성]**

비교 결과 통계만으로 보고서 문체(~함, ~임) 초안을 만들어 총평 칸 아래에 `[자동 초안 · 통계 기반 · 날짜 · 검토 필요]`로 덧붙입니다. 같은 자료면 언제나 같은 문장이 나옵니다.

| 항목 | 내용 |
|---|---|
| 1. 개정 개요 | 조항 수 변화, 변경 건수·비율(수정·추가·삭제·이동), 번호만 바뀐 조항, 개정 규모(변경 비율 60%↑ 전면 개정에 가까운 / 25%↑ 상당 부분 / 5%↑ 일부 / 그 밖 소폭) |
| 2. 장별 변경 | 변경이 많은 장 3개, 변경 없는 장 |
| 3. 주요 변경 사항 | 신설·삭제·이동 조항, 변경 폭이 큰 조항 5개(유사도), 그 조항에 적은 변경 사유 |
| 4. 표·그림 변경 | 표 내용·캡션 변경, 그림 캡션 변경·삭제 건수 (변경이 있을 때만) |
| 5. 제안 반영 결과 | 접수·반영·부분반영·미반영·미심의 건수, 반영률 |
| 6. 검토 시 유의 사항 | 자동 점검: 사유 없는 변경 조항, 미심의 제안, 조항 인용 확인, 직접 수정 조항, 수동 연결 조항, 그림 확인 |

"주요 개정 방향" 같은 해석은 통계로 만들 수 없으므로 작성자가 직접 다듬습니다. 문장 규칙은 `src/author/js/app.js`의 `statsDraft()`에서 고칩니다.

## 2. LLM 요청문 내려받기 (수동 처리)

같은 화면의 **LLM 요청문 [TXT 내려받기] / [PDF 내려받기] / [복사]**

- **TXT**: `LLM요청문_<교범명>_<날짜>.txt` (UTF-8). 사용 방법 → `여기부터` ~ `여기까지` 사이에 [지시]와 [자료].
- **PDF**: 인쇄 창이 열립니다. 대상(프린터)을 **"PDF로 저장"**으로 고르고 저장합니다(외부 프로그램 없이 브라우저 기능 사용).
- 처리 순서: ① 요청문을 폐쇄망 LLM 입력창에 붙여넣기 → ② 결과를 총평 칸에 붙여넣기 → ③ 수치·조항 번호를 통계와 대조.
- 요청문에는 변경 통계, 조항 번호, **바뀐 문구 일부(조항당 약 120자)**, 작성자가 적은 변경 사유가 들어 있습니다. 교범 등급에 맞게 다룹니다.
- 요청문 내용은 `src/author/js/llm.js`의 `SYSTEM`(지시), `buildPrompt()`(자료), `requestText()`·`requestHtml()`(파일 모양)에서 고칩니다.

## 3. 폐쇄망 LLM을 직접 연결하려면 (나중에)

`src/author/js/llm.js`의 `[보관] 폐쇄망 LLM 직접 연결` 블록:

1. `CLOSED_CONFIG`와 `draftSummary()` 주석을 풀고 `endpoint`·`model`을 채웁니다. (OpenAI 호환 `POST /v1/chat/completions` — vLLM, Ollama `/v1`, TGI 등)
2. `return`에 `draftSummary`를 추가하고, `app.js`의 총평 버튼 줄에 "LLM 초안" 버튼을 붙여 `LLM.draftSummary(llmPrompt())` 결과를 총평 칸에 덧붙이게 합니다.
3. `python src/build.py`로 다시 묶습니다.

확인할 점:
- **CORS**: `file://`로 열면 출처가 `null`이라 LLM 서버가 막을 수 있습니다. 내부망 웹서버(nginx 등)에 HTML을 올리고 같은 주소의 `/llm/` 경로로 LLM을 중계하는 방식을 권장합니다.
- **인증 토큰**은 HTML에 넣지 말고 중계 서버에서 붙입니다.

## 4. 보관 중인 Google Gemini 코드

인터넷 환경에서 Gemini 무료 API를 쓰던 버전(git 커밋 `5b82b05`~`3395f84`)의 핵심 호출 코드가 `llm.js`에 주석으로 남아 있습니다. 무료 키는 보낸 내용이 Google 서비스 개선에 쓰일 수 있어 비공개 교범에는 쓰지 않습니다. 이전 버전에서 브라우저에 저장했던 키(`singu-gemini`)는 지금 버전에서 쓰지 않습니다.
