작성: 2026-11-03 · 상태: **준비만 함, 미연결**

[LLM 요청문 복사]는 연결 전에도 쓸 수 있습니다. 내부 LLM 채팅 화면이 있다면 복사한 요청문을 붙여넣어 총평 초안을 받을 수 있습니다.

## 2. 연결 순서 (서버가 준비되면)

1. **서버 형식 확인**: 폐쇄망 LLM 서버가 OpenAI 호환 `POST /v1/chat/completions`를 지원하는지 확인합니다. vLLM, Ollama(`/v1`), TGI, LM Studio 등 대부분이 지원합니다. 다른 형식이면 `draftSummary()`의 요청 본문과 응답 파싱(`choices[0].message.content`)만 바꾸면 됩니다.
2. **주석 해제**: `llm.js`의 `CONFIG` 블록과 `draftSummary()` 안의 `fetch` 블록 주석을 풀고, `endpoint`·`model`을 채웁니다.
3. **켜기**: `ENABLED = true`로 바꿉니다.
4. **다시 묶기**: `python src/build.py` 실행 → `교범비교도구.html`에 반영됩니다.
5. **확인**: [종합 평가] → [AI 총평 초안 생성]을 누르면 총평 칸에 `[AI 초안 · 검토 필요]` 표시와 함께 초안이 덧붙습니다.

## 3. 반드시 확인할 점

### 3.1 브라우저 보안(CORS) — 가장 흔한 실패 원인
- 이 도구는 `file://`로 열리므로 요청 출처(Origin)가 `null`입니다. LLM 서버가 CORS 응답 헤더를 주지 않으면 브라우저가 요청을 막습니다.
- 해결 방법 (하나 선택):
  - **(권장) 중계 서버(프록시)**: 내부망 웹서버(nginx 등)에 이 HTML을 올리고 같은 주소 아래 `/llm/` 경로로 LLM 서버를 중계합니다. 그러면 같은 출처라 CORS 문제가 없고, 인증 토큰도 중계 서버에만 둘 수 있습니다.
  - **LLM 서버에 CORS 허용**: `Access-Control-Allow-Origin`을 허용 대상으로 설정합니다. `null` 출처 허용은 보안상 권장하지 않습니다.
- 내부망 HTTPS 페이지에서 `http://` LLM 주소를 부르면 혼합 콘텐츠로 막힙니다. 주소 체계를 맞춥니다.

### 3.2 인증 정보
- API 키를 HTML 파일에 넣으면 파일을 가진 모든 사람이 볼 수 있습니다. 키가 필요하면 **중계 서버에서 붙이도록** 하고, `CONFIG.apiKey`는 비워 둡니다.

### 3.3 보내는 데이터
- 요청문에는 **통계, 조항 번호, 변경된 문구 일부(조항당 약 120자), 작성자가 적은 사유**가 들어갑니다. 교범 전문은 보내지 않습니다.
- 교범 등급(비밀 여부)에 따라 해당 LLM 서버에 보내도 되는지 보안 담당과 먼저 확인합니다.
- 요청문 길이는 약 6,000자 이내로 자릅니다(`buildPrompt`). 모델의 입력 한도가 작으면 이 값을 줄입니다.

### 3.4 결과 다루기
- AI 초안은 총평 칸에 **덧붙이기만** 하고 기존 내용을 지우지 않습니다. 앞에 `[AI 초안 · 검토 필요]`를 붙입니다.
- 지시문에서 "주어지지 않은 사실은 지어내지 말 것"을 요구하지만, 수치·조항 번호는 반드시 사람이 확인합니다.

## 4. 바꿀 만한 곳

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 총평 구성·문체 변경 | `llm.js`의 `SYSTEM` |
| 요청문에 넣는 자료 추가·축소 | `llm.js`의 `buildPrompt()`, `app.js`의 `llmPrompt()` |
| 응답 시간 제한, 답변 길이 | `CONFIG.timeoutMs`, `CONFIG.maxTokens` |
| 다른 화면에서도 쓰기 (예: 변경 사유 초안) | `LLM.draftSummary()`를 다른 지시문으로 호출하는 함수를 추가 |
